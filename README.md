# MathQuest9

## Automatic Android APK Builds

This project builds an Android APK with GitHub Actions. It does not use Expo Go, EAS Build, or any Expo/EAS login.

After pushing to GitHub:

1. Open the GitHub repository.
2. Go to **Actions**.
3. Open the latest **Build Android APK** workflow run.
4. Scroll to **Artifacts**.
5. Download **MathQuest9-release-apk**.

The downloaded artifact contains the release APK generated by Gradle.

If the release build fails, add a debug APK fallback workflow that runs:

```sh
./gradlew assembleDebug
```
