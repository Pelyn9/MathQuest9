# MathQuest9

## Automatic Android APK Builds

This project builds an Android APK with GitHub Actions. It does not use Expo Go, EAS Build, or any Expo/EAS login.

After pushing to GitHub:

1. Open the GitHub repository.
2. Go to **Actions**.
3. Open the latest **Build Android APK** workflow run.
4. Scroll to **Artifacts**.
5. Download **MathQuest9-release-apk**.

The downloaded artifact contains the release APK generated by Gradle. If the release build fails, the workflow tries a debug APK fallback and uploads **MathQuest9-debug-apk** instead.

You can also run the build manually from **Actions** > **Build Android APK** > **Run workflow**.

The debug fallback uses:

```sh
./gradlew assembleDebug
```
